# Accueil Tonio

Page d'accueil de mes apps : liens directs, résumé de chaque app (lu dans le dossier Drive « Tonio », lecture seule), état des sauvegardes et points d'attention du jour.

- Un seul fichier : `index.html` (aucune donnée dedans).
- Les résumés sont lus dans le navigateur depuis `Mon Drive/Tonio/<app>/<app>_latest.json`. Rien n'est envoyé ni enregistré ailleurs.
- Chrome ou Edge sur PC pour relier le dossier ; sur iPhone : liens + choix manuel des fichiers.
